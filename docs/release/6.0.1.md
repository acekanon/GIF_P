# GIFP 6.0.1 源码预览

日期：2026-09-10。版本：6.0.1。渠道：GitHub 源码预览。

本次将 6.0 多素材剪辑工作台和 6.0.1 字幕/贴纸时段联动同步到 GitHub。
产品变化见 [更新记录](../../CHANGELOG.md)，运行方法见 [README](../../README.md)。

## 发布内容

- React / TypeScript 前端、Tauri / Rust 原生后端及锁定依赖。
- Animal-Island-UI 主题与应用实际使用的角色动效资源。
- 编辑、合成、GIF 压缩、格式交付、录屏、表情组与工程持久化实现。
- 单元测试、合成测试夹具、质量实验工具、许可文件与发行校验脚本。

源码从本地工作区整理到独立发布目录，基于 GitHub 原主分支提交；没有把本地
测试视频、录屏截图、实验产物、内部程序或 FFmpeg 二进制加入 Git。

## 验证

验证环境为 Windows、Node.js 24.18.0、npm 11.16.0、Rust 1.97.1；原生媒体回归
使用本机锁定的 FFmpeg 9.0 shared 运行时。先在独立目录执行 `npm ci`。

| 检查 | 结果 |
| --- | --- |
| TypeScript / Vite 生产构建 | 通过；最终 TypeScript 检查通过 |
| 前端回归 | 508 项均有通过记录，执行情况见下方 |
| Rust release 回归 | 502 项库测试 + 9 项实验统计工具测试通过；31 项离线/环境专项明确 ignored |
| Rustfmt / Clippy | 通过；release/all-targets，`-D warnings` |
| 发行、平台证据与 FFmpeg 构建校验脚本 | 60 项通过；平台证据文件校验通过 |
| 录屏选区事件回归 | 通过；包含松手后冻结、反向框选、最小尺寸和负坐标桌面 |

前端首轮全量执行有 40 个文件、399 项通过；另一个 109 项页面回归文件出现旧版
断言及超时。修正固定版本断言后，该文件单独复跑 108 项通过，剩余 Live Photo
用例保持原有 10 秒限制隔离运行通过（约 7.3 秒）。因此 508 项均已覆盖，但本轮
**没有取得单次全量无超时的结果**，大型 UI 套件的时限敏感性仍需改善。未提高
超时上限、删除业务断言或把失败用例设为跳过。

生产构建保留一个非阻断提示：前端主块超过 500 kB，后续可进一步拆分加载。

这些检查不替代 Windows 便携包的完整交互验收，也不是画质排名或压缩极限证明。
外部素材基准和明确标记 ignored 的离线实验不会作为默认测试已通过计入。

## 安装包状态

本次 Release 仅提供 GitHub 自动生成的源码归档。当前本地 6.0.1 便携包属于
`internal` 渠道，公共 FFmpeg 9.0 LGPL 运行时的构建、能力复审、可复现验证和
对应源码归档尚未完成；相关配置保持 `publicAlphaAllowed: false`。

因此不上传内部 EXE、FFmpeg、DLL 或便携 ZIP，也不将源码预览标为正式 Windows
发行版。具体条件见 [发行流程](RELEASE-COMPLIANCE.md)。

## 已知限制

- 工程工作台目前导出 GIF，画布是不透明背景；完整透明画布尚未交付。
- 普通真实预览最多前 15 秒；当前帧精确预览使用工程画布尺寸。
- 工程最长 5 分钟，并受画布、图层、关键帧、像素帧及内存预算限制；工程文件上限 8 MiB。
- 工程保存素材引用，素材移动后需要重连；撤销栈不随工程文件保存。
- 时段联动保护锁定图层；主轨重排不建立字幕/贴纸与素材的自动绑定。
- 浏览器模式提供交互演示，真实本地合成与导出需要桌面运行时。
- 时域量化与 LZW 新研究候选尚未作为工作台策略发布。
