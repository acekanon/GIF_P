# GIF_P 1.2 版本设计方案

## 目标

1.2 版本的核心不是堆功能，而是把 GIF_P 从“能压 GIF 的可爱工具”升级成“像轻量剪辑器一样顺手的表情包工作台”。重点是让用户更直观地决定输出片段，更自由地保存自己的压缩风格，并用皮肤和滤镜把软件的个性做出来。

## 版本优先级

### P0：时间轴帧段裁剪

现状：起始帧、结束帧是纯数字输入，功能可用但不直观。

1.2 应改成中间预览下方的时间轴：

- 显示视频缩略帧条，类似剪辑软件里的胶片轨道。
- 左右两个拖拽手柄控制 GIF 输出范围。
- 输入框保留，作为精确校准。
- 拖动时实时显示起始帧、结束帧、预计时长。
- 点击“播放选区”只循环预览选中片段。

实现建议：

- 后端新增 `extract_timeline_frames` 命令，用 FFmpeg 从视频均匀抽 8-12 张 jpg/png 缩略图到临时目录。
- 前端新增 `TimelineTrimmer` 组件，显示缩略图、轨道、左右手柄。
- 数据仍复用现有 `start_frame` / `end_frame`，不改导出协议。

风险：

- 抽缩略图会增加导入耗时，需要异步加载。
- 批量模式只对首个视频显示时间轴；批量文件默认复用同样帧段参数。

### P1：自定义预设

现状：4 个固定预设写在 `App.tsx` 里。

1.2 应增加“保存为我的预设”：

- 用户调好宽度、帧率、颜色数、抖动、有损阈值、优化级别后，可以保存成一个按钮。
- 自定义预设显示在 4 个官方预设下方。
- 支持删除自定义预设。
- 如果本机存储失败，软件仍可正常使用官方预设。

实现建议：

- 优先使用浏览器 `localStorage`，Tauri WebView 下可以保存简单 JSON。
- 存储 key：`gif_p.custom_presets.v1`。
- 预设结构与现有 `PRESETS` 对齐，但增加 `custom: true`。
- 不进入 Rust 后端，避免扩大风险。

### P1：皮肤系统

目标：让 GIF_P 从“儿童画 4 色风格”扩展成可替换主题。

第一阶段做 3 套：

- 默认儿童画：当前版本。
- 像素游戏机：深色底、绿色/蓝色像素屏、CRT 扫描线。
- 可爱贴纸：允许用户放入背景图、动态图或装饰图。

实现建议：

- 用 CSS 变量实现主题色。
- `public/skins` 或 `src/assets/skins` 放内置皮肤资源。
- 用户自定义皮肤先做“背景图路径输入”，后续再做完整皮肤包。
- 皮肤选择保存到 `localStorage`。

注意：

- 动图背景不能影响预览区可读性。
- 皮肤只改变外观，不改变导出 GIF。

### P2：GIF 滤镜

定位：不是修图软件，而是“表情包风格化滤镜”。

建议 1.2 先做 5 个可解释滤镜：

- 原味：不加滤镜。
- GB 绿屏：灰绿调色 + 低色阶。
- GBA LCD：轻微网格 + 提亮 + 色彩压缩。
- CRT：扫描线 + 轻微锐化 + 暗角。
- 像素海报：低分辨率缩放 + 邻近采样 + 少色彩。

实现建议：

- 前端新增滤镜选择项。
- 后端 `CompressionRequest` 增加 `filter_style`。
- Rust 中把滤镜转换为 FFmpeg filter chain，插在 `prefilter` 后、`fps` 前。
- 第一版滤镜尽量用 FFmpeg 原生 filter，避免引入复杂图像库。

可能的 FFmpeg 方向：

- GB：`hue=s=0,curves` 或 `colorchannelmixer`。
- GBA LCD：`eq` + `unsharp` + `drawgrid` 近似。
- CRT：`drawgrid` / `noise` / `vignette`。
- 像素海报：先低分辨率 `scale`，再 `scale=flags=neighbor` 放大到目标尺寸。

## 我建议的 1.2 切分

### 1.2-alpha

- 时间轴缩略图轨道
- 左右拖拽手柄
- 起止帧数字同步
- 保持导出速度不变

### 1.2-beta

- 自定义预设保存/删除
- 作者署名保留
- 皮肤选择：默认、像素游戏机、可爱贴纸

### 1.2-final

- 5 个 GIF 风格滤镜
- 滤镜和预设联动
- 分发包 README 更新
- 重新打包 exe

## 推荐补充脑洞

- “一键表情包模式”：自动裁短到最有动作变化的 1-3 秒。
- “循环点优化”：尽量让 GIF 开头和结尾更顺。
- “输出前对比”：原视频片段 vs GIF 预览同屏。
- “平台预设”：微信、QQ、B站评论区、Discord、网页小图。
- “压缩解释器”：导出后用一句话解释为什么这个 GIF 是这个体积。

## 成功标准

- 用户不看说明也能拖动时间轴截片段。
- 自定义预设关闭重开后仍存在。
- 皮肤不会遮挡核心操作。
- 滤镜不是玩具，至少 GB/GBA/CRT 三个能明显看出风格。
- 新功能不破坏现有批量生成和画面裁剪。
