# GIFP 平台交付实机验证规程

## 结论边界

平台“已实机验证”只适用于证据中明确记录的客户端、操作系统、策略版本和输出规格。官方格式文档、参数经验或更小文件都不能自动升级为实机验证。

## 首批 Windows 验证矩阵

| 交付面 | 固定素材 | 必须完成的链路 |
| --- | --- | --- |
| QQ 聊天动图 | 普通运动 GIF、文字边缘 GIF | 发送、另一账号播放、转发、下载、GIFP 重开 |
| 微信聊天动图 | 普通运动 GIF、文字边缘 GIF | 发送、另一账号播放、转发、保存、GIFP 重开 |
| 微信收藏表情 | 方形短 GIF、透明/文字边缘 GIF | 导入、播放、转发、保存、GIFP 重开 |
| 飞书聊天动图 | 普通运动 GIF、文字边缘 GIF | 发送、另一账号播放、转发、下载、GIFP 重开 |

不要把 Windows 结论泛化为 iOS、Android 或 macOS。小红书、抖音 Live 图需要在对应移动客户端另建证据。

## 每条证据必须记录

- 平台策略 ID 与 revision。
- 精确客户端名称、版本、Windows build 和测试时间。
- 固定测试素材、发送前成品和证据包的 SHA-256。
- 格式、宽高、帧率、时长和真实字节数。
- `send`、`receiverPlayback`、`forward`、`download`、`reopen` 五项结果。
- 下载后文件的尺寸、帧率、时长、帧数、Alpha、循环和 SHA-256；平台转码时明确记录 `transformed`，不得伪报原文件直通。

## 证据生命周期

- 默认有效期 180 天。
- 客户端大版本、平台策略 revision 或交付入口变化后立即复验。
- 任一生命周期步骤缺失、证据哈希无效、测试日期位于未来或输出超出已测规格时，GIFP 必须降级为“仅规则推断”或“证据已过期”。
- 证据包不得包含聊天内容、账号标识、联系人、访问令牌或未脱敏截图。

## 当前状态

5.7.11 已实现证据校验、过期降级、具体目标绑定和输出信心隔离。仓库当前没有外部客户端实测证据，因此 QQ、微信、飞书、小红书和抖音仍不会显示“已实机验证”。必须完成上述人工/受控客户端链路后才能提交证据。
